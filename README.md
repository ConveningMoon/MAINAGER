# MAINAGER

Контур управления между автономным агентом и генеративным API: что вызвать,
стоит ли вызывать, сколько это стоило и был ли результат пригоден.

> Ваш агент — не проблема. Проблема в том, что между агентом и деньгами клиента
> нет контура управления.

Проект в работе. Архитектура, находки по API и разбор расходов — в `FINDINGS.md`
и `COSTS.md`.

## Быстрый старт

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env        # вписать токен вида oc_...
mainager capabilities       # выгрузить каталог моделей в data/capabilities.json
```
